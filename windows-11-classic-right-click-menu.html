Get the full right-click menu back in Windows 11

Windows 11 shows a short menu and hides the rest behind "Show more options". Here is how to see the full menu, once or always, and how to undo it.

On this page

  1. 1. Just this once
  2. 2. Make it permanent
  3. 3. Undo it
  4. 4. With one switch

Just this once

Hold Shift while you right-click, or select an item and press Shift+F10. Windows 11 skips the short menu and opens the full classic one straight away. Nothing is changed on your PC.

Make it permanent

A per-user registry key turns the short menu off. It needs no administrator rights. Open Terminal or Command Prompt and run:

reg add "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32" /f /ve

Then restart Windows Explorer so it takes effect. You can restart your PC, or run:

taskkill /f /im explorer.exe & start explorer.exe

The setting works on current Windows 11 builds. It relies on behaviour Microsoft has not documented, so a future update could change it.

Undo it

Delete the key you added, then restart Explorer again:

reg delete "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}" /f

With one switch

Context Menu Editor makes the same change from a switch, and lets you turn it back off the same way. Open its Tweaks page and switch on Classic right-click menu. It also restarts Explorer for you. Paste this into PowerShell:

Run Context Menu Editor

irm https://rocisapps.com/cme | iex

Free and open source. Nothing is installed, and every edit or delete is backed up first.

While you are there, the editor can also turn off the entries you never use and remove leftovers from apps you uninstalled. See how to remove items from the right-click menu.
