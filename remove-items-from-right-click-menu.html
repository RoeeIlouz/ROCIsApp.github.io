How to remove items from the right-click menu in Windows

Apps add entries to the right-click menu when you install them, and many stay behind when you uninstall. Here is where they live, how to remove them by hand, and a safer way.

On this page

  1. 1. Where entries come from
  2. 2. Remove them with the registry
  3. 3. Send to and New
  4. 4. The easier way

Where entries come from

Windows builds the right-click menu from three different places, and each is removed differently:

  • Commands (verbs) under a shell key, such as "Open with Code".
  • Shell extensions under a shellex\ContextMenuHandlers key, added by programs like 7-Zip or your antivirus.
  • Windows 11 menu items that apps register through their package. They have no command line, so they do not show up under a shell key.

Remove them with the registry

Open Registry Editor (regedit). Before you change anything, back up the key: right-click it and choose Export. Entries under HKEY_LOCAL_MACHINE apply to all users and need administrator rights; entries under HKEY_CURRENT_USER do not.

Commands

Look under HKEY_CLASSES_ROOT\*\shell for files, Directory\shell for folders and Directory\Background\shell for the empty space in a folder. To hide a command without deleting it, add a string value named LegacyDisable to its key. To remove it, delete the key.

Shell extensions

Look under shellex\ContextMenuHandlers in the same places. Deleting a handler removes it for good. A gentler way is the block list: under HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Shell Extensions, create a key named Blocked and add a string value named after the handler's CLSID (the {...} value). Restart Explorer afterwards. The same block list hides Windows 11 packaged items.

Matching a name to its CLSID by hand is slow, and the wrong deletion can break an app. That is the main reason to use a tool.

Send to and New

The Send to menu is a folder of shortcuts. Press Win+R, type shell:sendto, and delete or move the shortcuts you do not want. The New menu is controlled by ShellNew keys under each file type; renaming a type's ShellNew key to _ShellNew hides it without deleting it.

The easier way

Context Menu Editor shows every entry in one list, with a switch for each. Turning one off keeps it, so you can bring it back. It also finds entries that point to programs that no longer exist, and backs up anything you edit or delete first.
