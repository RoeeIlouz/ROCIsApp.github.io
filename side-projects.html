Context Menu Editor

  • Windows 10 and 11
  • PowerShell
  • Open source (MIT)

See everything in the Windows right-click menu and clean it up. Turn entries off without deleting them, add your own commands and submenus, tidy up New and Send to, and undo any change.

Paste this into PowerShell to run it

irm https://rocisapps.com/cme | iex

Nothing is installed. It always runs the latest release, and backups stay on your PC.

Source code Releases

Related guides: get the full right-click menu back in Windows 11 and remove items from the right-click menu.

  • Everything in one list. Classic commands, shell extensions and Windows 11 menu items, filtered by where they appear: files, folders, the desktop, drives or one file type.
  • Off, not gone. Turning an entry off keeps it, and anything you edit or delete is backed up first.
  • Your own commands. Add commands and submenus, then try them with the Test button before they reach the menu.
  • New and Send to. Hide file types from New, and add apps to Send to, grouped into their own submenu.
  • Broken entries. Finds leftovers from uninstalled apps and removes them in one step.
  • Windows 11 full menu. One switch brings back the classic right-click menu without "Show more options".
